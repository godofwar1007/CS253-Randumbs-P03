# D6 benchmark and figure commands

The benchmark accepts a Release simulator executable built by the team's
existing build. It keeps analysis separate from the tree implementations.
All three D6 tools use C++17. The figure generator writes SVG directly and
uses no plotting library.

From the repo root, once the prediction is committed:

```sh
g++ -std=c++17 -O2 docs/analysis/pred.cpp -o build/d6_pred
g++ -std=c++17 -O2 bench/d6_run.cpp -o build/d6_run
g++ -std=c++17 -O2 results/d6_figures.cpp -o build/d6_figures
build/d6_pred > results/raw/d6_prediction.csv
build/d6_run build/simulator results/raw/d6_uniform
build/d6_figures results/raw/d6_uniform results/raw/d6_prediction.csv results/figures/d6_uniform
```

On Windows, build to executable names with the `.exe` suffix and pass the
actual simulator path, such as `build/Release/simulator.exe`. In Windows
PowerShell pipe the prediction program to
`Set-Content -Encoding ASCII results/raw/d6_prediction.csv`.
The runner expects a fresh output directory. Use `--smoke` with a separate
build output directory to check the pipeline with 2n pairs per run.

The order of runs and the five seeds are fixed. Each run records the
strategy, size, schedule, seed, pair budget, elapsed time printed by the
simulator, and sample filename. Elapsed time includes workload generation
and sample writes during churn and excludes initial tree construction.
The simulator exports cumulative rebuild counts. These counts combine
subtree and root rebuilds. The figure generator reports mean and sample standard
deviation and produces per-seed model comparisons for uniform churn.

Before collecting graded data, record the machine, OS, CPU/cache sizes,
compiler and flags, repo commit, and the command line used. Save profiler
output alongside timings if the report makes a cache claim.

The current simulator factory accepts only `uniform`. After D3 and D5
expose the intended schedules, use `--schedule NAME` and a separate
output directory per schedule. Confirm each target with D5 before
comparing it with the corresponding uniform baseline.
